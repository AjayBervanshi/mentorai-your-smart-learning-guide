## 2024-06-03 - Exposing Supabase Error Details via Toasts
**Vulnerability:** Supabase auth operations exposed the raw error messages via `err.message` to the user via toast UI notifications, leaking internal details.
**Learning:** Returning `err.message` from auth actions unmasked can expose internal constraints or table structures and allows for enumeration attacks.
**Prevention:** Instead of exposing `err.message`, log the error to the console for debugging and present generic UI messages to the user (e.g., "Authentication failed. Please try again.").
